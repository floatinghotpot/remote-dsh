## 1. Manus（蝴蝶效应 Butterfly Effect，现腾讯控股）—— 云端自主执行型通用 Agent

- **一句话定位**：给一句话就能在云端自主规划并多步骤执行任务的"通用智能体"（浏览器即用、自带云端计算环境），是"云端免部署 agent"品类的标杆。
- **背景与股权**：母公司为蝴蝶效应（Butterfly Effect，创始人季逸超，旗下还运营 AI 助手 Monica）。2025-12 报道 Meta 以约 $20 亿收购 Manus；2026-07 报道腾讯以约 $20 亿从 Meta 手中收购其股份成为最大股东，Manus 恢复独立公司运营（为合规与未来港股上市铺路）。据报道年化收入已升至 $4–5 亿（腾讯接盘时）。
- **定价/计费（积分制，订阅 + 积分）**：
  - 首发价（2025-03-31，TechCrunch/IT之家）：Starter $39/月（3,900 积分，最多 2 个并发任务）；Pro $199/月（19,900 积分，最多 5 个并发任务，含高投入模式）。
  - 现行价（2026，Lindy 整理 + Penchan 教程，**以官网为准**）：Free $0（1,000 起始积分 + 300 积分/日刷新）；Pro（标准用量）$20/月 ≈ 4,000 积分/月；Pro（定制用量）$40/月 ≈ 8,000 积分/月；Pro（扩展用量）$200/月 ≈ 40,000 积分/月；Team $40/座/月（至少 2 座，每座 4,000 积分，团队共享积分池）。
  - 积分消耗：Chat 模式免费；Agent 模式按任务消耗，简单查询约 10–50 积分，深度研究约 500–900 积分；官方示例"设计并部署个人网站"约 600 积分、40 分钟。
  - 积分规则：月额度不结转、月底清零；免费积分与加购积分可保留（付费期内）。**用户最大痛点：积分消耗不可预测（实测常为官方估算 2–4 倍）**。
- **目标用户**：需要"外包"长时间多步骤任务（深度研究、报告、建站、数据分析）的个人知识工作者与团队。
- **是否云端运行/免部署**：✅ 是。云端自主执行（自带计算环境），浏览器即用，无需用户设备常开。

## 对我们的启示（rdsh 08/09/10 线）

1. **"云端免部署 agent"已是被验证并快速货币化的品类，定价锚点集中在 $20/月（轻）与 $199–249/月（重）两档**：Manus（$20/$40/$200）、Devin（$20/$200）、Genspark（$24.99/$249.99）、Monica（$9.9 起）几乎收敛在同一区间；国内扣子按人民币锚定（¥39.9/¥99/¥199/¥999）。我们的 09 线（云端租 DSH）若按"托管 + 使用额度"打包，个人轻档可锚 $20/月附近、重度档 $100–200/月，避免低于 $9.9 的廉价档拉低感知价值。
2. **"订阅送额度 + 超出按量/积分"是行业主流混合模型，纯订阅正被积分制侵蚀**：Manus/Devin/Monica/Genspark 全部是"订阅含积分池 + on-demand credits 充值"，且积分"不滚转、月底清零、消耗不可预测"是用户最大投诉点——这是我们的差异化机会：**要么承诺"额度可结转"，要么用"托管算力 + 明确单位定价"（类似无影的灵豆/小时）提供可预期的账单**，直接把"积分焦虑"做成卖点。
3. **平台免费、模型按量是国产大厂路线（元器/百炼/扣子早期），独立产品的钱主要收在"托管执行环境 + 编排"而非模型本身**：腾讯元器与百炼证明模型 API 按量已成白菜价（qwen-plus 输入 0.8 元/百万 tokens、元器混元 0.0045 元/千 tokens），单卖 token 转售（我们的 10 线）毛利空间被官方直营压薄，**必须与"免部署环境 + hub 托管"捆绑销售**才有溢价；这与 Dify 开源 + 云版收"平台费"的路径一致。
4. **开源/自托管与云版并行是增长飞轮，但多租户商用有授权红线**：Dify 以开源获客、云版收 $590–$1,590/年，同时其"修改版 Apache 2.0"明确限制他人用其源码做多租户 SaaS。我们 rdsh 自身开源（MIT）而 hub 托管收费（08 线）正是同一模式；反向启示是：**若未来做"DSH 云端多租户"（09 线），要确认 DSH 生态（如 dsh 插件）授权不构成对 DSH 自身的多租户商用限制**，并把"用户自带机器接入 hub"（08 线）作为绕开算力重资产的差异化护城河——Manus 模式（重算力自营）与扣子模式（平台 + 生态分发）之间，我们的位置更靠近"轻资产连接层"。
