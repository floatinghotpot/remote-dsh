## 1. 定位声明

**三句话**：
1. **给开发者与准技术人群**：把 DeepSeek Harness 变成"任何地方浏览器即用的智能体"——免部署、免公网、免装客户端（08 托管 hub）。
2. **给效率人群（未来）**：点一下创建云端 DSH，浏览器派活，用完释放（09，等闸门）。
3. **给团队**：一个账号管多台机器 + 共享/审计/按席位付费。

**目标用户（首版）**：开发者 + 准技术人群（分析师/运维/小团队），以 DSH 生态用户为主；白丁是 AaaS 愿景（后置）。

**不做清单**：不做大模型（用 DeepSeek）；不做重算力自营（用户自带机器/自己租 ECS）；不正面拼大厂流量与补贴；白丁市场不进首版。

## 2. 北极星与战略意图

- **北极星**：让用户用最少的力气用上通用智能体（浏览器即用、免部署）——"coding agent"只是第一个甜点场景。
- **双分支战略**：证明技术 + 商业模式跑通 → ① 商业与法律允许 → 独立运营向前；② 受阻 → 后撤，转向**出售/合作**（DeepSeek / 阿里云 / 腾讯）。
- **核心资产 = "agent 连接层"**（hub + join + gateway + dsh 插件 + 协议契约）：可嵌入、可白标、可收购；MIT 开源 + 层 1/层 2 契约冻结保证资产可迁移。

## 4. 商业模式假设（定价锚点，待 S1 数据校准）

- **08**：订阅制（Free 拉新 → $20/月个人档 → 团队席位）；价值 = 免部署/免公网/账号体系；
- **09**：包月套餐 + 按小时算力双轨（对标无影/Devin；成本锚 2C2G ¥45/月目录价，转售 2–5 倍加价空间）；
- **10**：成本 pass-through + 平台费（OpenRouter 式 5.5% 量级）或"订阅含额度 + 超量按量"；
- **差异化卖点**：额度可结转 / 账单可预期 / 浏览器免部署（vs 竞品"积分不结转、要装客户端"）。

## 5. 里程碑与闸门

**里程碑**：08 按 S1（注册/试用/配额）→ S2（订阅状态机 + PaymentProvider mock）→ S3（招行聚合真实支付）→ S4（反滥用/安全/运营）；09/10 待闸门。

**商业闸门**（S1 数据出来后校准数字）：试用→付费转化率、付费用户数、MRR 达阈值；
**法律闸门**：10 转售授权（或放弃转售只做 08）、09 B11 确认、资质/备案/AI 内容标识全落地；
**触发后撤**：任一闸门未过 → 停止独立运营投入 → 转向出售/合作（连接层资产 + 用户数据仍具价值）。

**风险不对称**：08 是纯软件（hub 已自用、支付/邮件基建已具备），单独做 08 即能零风险验证付费意愿；09/10 才引入资源/合规敞口，故等闸门。

## 6. 风险清单与复核节奏

| 风险 | 应对 | 复核 |
|---|---|---|
| 竞争（大厂免费补贴、Manus/Coze） | 差异化在连接层 + 免部署空白；不正面拼 | 季度竞品动态复核（2026 行业按量转向快） |
| 成本波动（DeepSeek 涨价 1100%/停充） | 10 用 pass-through + 平台费；错峰/缓存优化 | 每里程碑 |
| 合规（转售授权 / B11 / AIGC 义务） | 合规清单逐条核；授权方=潜在买家（被战略消化） | 上线 gate |
| 授权红线（Dify 禁多租户 SaaS / DSH 生态待核） | 09 前核查 DSH 授权 | 09 立项前 |
| 付费意愿未验证（头号假设） | 08 最小验证（S1 漏斗） | S1 里程碑 |

## 7. 关键假设清单（显式列出，待证伪/证实）

1. **付费意愿**：08 托管 hub 有人愿付 $20/月 → S1–S3 验证；
2. **差异化空白成立**："浏览器免部署"暂无人占位 → S1 用户反馈验证；
3. **合规路径可行**：招行聚合签约顺利、10 转售授权可获（或被战略消化）→ S3 前确认；
4. **出售/合作有市场**：连接层资产可被巨头估值 → 长期（GitHub stars / 用户数 / 架构资产积累）。
