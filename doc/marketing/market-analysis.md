## 1. 目标与范围

**分析对象**：rdsh 商业化 SaaS 线（一条产品线，三个变现形态）：

| 形态 | 卖什么 | 用户自带什么 |
|---|---|---|
| **08 托管 hub** | 托管的多租户 hub（注册/试用/订阅/支付） | 用户自带机器（`rdsh host join`） |
| **09 云端 DSH** | 云主机转售 + dsh 预装（浏览器即用，无 SSH） | 用户自带 DeepSeek key |
| **10 Token 转售** | 模型调用额度（免 DeepSeek key） | 无（横切 08/09 全部用户） |

**北极星**（复述 2026-08-26）：让用户**用最少的力气用上通用智能体**——不是"coding agent"（coding 只是第一个甜点场景），而是"一台电脑 + 一个会干活的智能体"，任何地方（电脑/手机/微信内浏览器）直接可用、免部署。

**价值阶梯**（低门槛五级）：① LAN/VPN 远程访问 → ② 公网云主机直连 → ③ hub 免公网 IP → ④ SaaS 自助注册订阅 → ⑤ 云端租用（连机器都不用有）。08/09/10 对应 ④⑤ 及横切能力。

## 2. 用户与价值

### 2.1 目标用户细分

| 用户群 | 特征 | 核心痛点 | 对应形态 |
|---|---|---|---|
| **个人开发者** | 有 DSH/agent 使用习惯，机器性能/网络受限 | 机器不够好、出门在外连不上、不想折腾部署 | 08（自带机器接入）+ 09（租云环境） |
| **效率人群**（运营/分析/研究/自由职业） | 非重度技术，想"派活"给 agent | 不会装 agent、没有好机器、要浏览器即用 | 09（一键云环境）+ 10（免 key） |
| **小团队/工作室** | 多人协作、多台机器 | 统一账号、共享、成员权限、发票 | 08（团队席位/共享）+ 09（团队云环境） |

### 2.2 我们创造的价值（按 08/09/10）

- **08（连接层）**：把"自己搭 hub"降为"注册即用"——多台机器一个账号、任何地方浏览器访问、免公网 IP。价值 = **免部署 + 免公网 + 账号体系**。
- **09（环境层）**：把"要有一台好机器"降为"点一下创建"——dsh 预装、浏览器即用、用完释放。价值 = **免机器 + 免安装 + 按时计费**。
- **10（模型层）**：把"要注册 DeepSeek 充值"降为"用平台额度"——免 key、统一结算。价值 = **免模型账号 + 统一计费**。

三者叠加 = 完整闭环：用户什么都不用有，浏览器点几下就能派活给智能体。

## 3. 市场与需求

### 3.1 品类已被验证且快速货币化（需求真实）

- **Manus**（云端自主执行型通用 Agent）是品类标杆：2025-03 首发 $39/$199，现行 Free/$20/$40/$200 积分订阅；2025-12 Meta 约 $20 亿收购、2026-07 腾讯约 $20 亿接盘成最大股东，**年化收入据报 $4–5 亿**（[21jingji](https://m.21jingji.com/article/20260716/herald/96ed285374a9ecd60c5801ef20b77671.html)、[stheadline](https://www.stheadline.com/zh-hans/daily-finance/3604533/)）。
- **Devin**（Cognition，云端 AI 工程师）2026 self-serve：Free/$20/$200/Teams + ACU 按量（~$2.5/ACU），云端托管工作区、浏览器用（[docs.devin.ai](https://docs.devin.ai/admin/billing/self-serve)）——**最接近 09"云端租用环境"的对标**。
- **Genspark**（Super Agent）Free/$24.99/$249.99 积分制（[eesel](https://www.eesel.ai/blog/genspark-ai-pricing)）；**扣子 Coze**（字节）免费/¥39.9/¥99/¥199/¥999（[docs.coze.cn](https://docs.coze.cn/coze_pro_premium_package)）。

结论：**"云端免部署 agent"是已被 $2B 级交易和 $4–5 亿年收入验证的品类**，不是空想。

### 3.2 三个真实痛点（我们的切入点）

1. **机器/部署门槛**：传统远控（ToDesk/向日葵）、组网（Tailscale/ZeroTier/frp/ngrok）、云电脑（无影）**全都要装客户端/agent/CLI**，没有一家"开浏览器即用、无 SSH、无客户端"（[09 基准 §启示3]）。DSH 本身是 Web UI，rdsh 的浏览器免部署 + 认证网关正落在这个空白。
2. **积分焦虑**：Manus/Genspark/Devin 的积分"不滚转、月底清零、消耗不可预测"是用户最大投诉点（Manus 实测常为官方估算 2–4 倍；Genspark 有用户单命令烧 10K 积分）。
3. **模型 key 门槛**：要跑 agent 得自己注册 DeepSeek 充值——非技术用户流失点。

### 3.3 市场信号：coding → 通用 agent 的扩展

Devin 收购 Windsurf（$2.5 亿）、Cursor 从补全走向云端后台 agent、Codex/Claude 从 IDE 插件走向云端沙箱 + agent——**行业一致方向是"浏览器即用、免部署的通用 agent"**，正是我们的北极星。

## 4. 竞争分析

### 4.1 三类相邻竞品对比（详见各基准文档）

| 品类 | 代表 | 定价锚点 | 免部署？ | 与我们关系 |
|---|---|---|---|---|
| **云端 agent 平台** | Manus、Devin、Genspark、Coze、元器、百炼、Dify | $20/$199-249（国内 ¥39.9-999） | ✅（云端） | **直接竞品**——同品类同北极星 |
| **AI 编程工具** | Cursor、Copilot、Claude Code、Codex、Windsurf、Trae、Qoder | $20 铁锚，重度 $100-200 | ❌（本地 IDE 为主，正在云化） | 相邻——用户重叠（开发者），但我们是"远程访问 + 环境"，非编辑器 |
| **远程访问/云主机** | ToDesk、向日葵、无影、Tailscale、ZeroTier、frp、ngrok、轻量服务器 | 远控 ¥10-25/月；云主机 2C2G ¥45/月目录价 | ❌（要装客户端） | 相邻——我们的"连接层"功能重叠，但**免部署是空白** |

### 4.2 关键差异化空白（结论）

- **"浏览器免部署 + 无 SSH"**：三类竞品无一提供，是 09 独有叙事（"无影要装客户端，我们开浏览器就行"）。
- **"轻资产连接层"**：Manus/Devin 是**重算力自营**（要养 GPU 沙箱集群）；我们的 08 是**用户自带机器接 hub**，绕开算力重资产——成本结构与护城河不同（更轻、可开源获客）。
- **"额度可结转 / 账单可预期"**：竞品积分不结转、消耗不可预测，我们可用"托管算力 + 明确单位价（灵豆式按小时）"做差异化卖点。

## 5. 定位与差异化

**三句话定位**：
1. **给开发者**：把 DeepSeek Harness 变成"任何地方浏览器即用的智能体"，免部署、免公网、免装客户端。
2. **给效率人群**：点一下创建云端 DSH，浏览器派活，用完释放——不用懂机器、不用配模型 key。
3. **给团队**：一个账号管多台机器 + 云端环境，共享、审计、按席位付费。

**差异化四板斧**：① **开源 DSH 底座**（成熟 harness，零 agent 研发成本）；② **国产模型低成本**（DeepSeek V4-Flash 空闲档输出 ¥4.5/百万，为海外同档 1/4～1/16）；③ **浏览器免部署**（无 SSH/无客户端，竞品空白）；④ **轻资产连接层**（08 用户自带机器，避开 Manus 式重算力）。

**授权红线提醒**：Dify 用"修改版 Apache 2.0"禁止他人用其源码做多租户 SaaS（[LICENSE](https://raw.githubusercontent.com/langgenius/dify/main/LICENSE)）——反证"开源获客 + 托管收费"可行，但我们自己 MIT 开源 + 08"用户自带机器"是合法且轻的路径；09 做"DSH 云端多租户"前须核查 DSH 生态授权不构成对 DSH 自身的多租户商用限制（待查证）。

| 锚点 | 数值 | 来源 |

| 重度/云端 agent 档 | **$100–200/月**（Claude Max、Codex Pro $100、Cursor Ultra $200、Manus $200、Devin $200） | 同上 |
| 国内平台档 | ¥39.9 / ¥99 / ¥199 / ¥999（Coze） | coze 基准 |
| 远控订阅 | 个人 ¥10–25/月、团队 5 席位 ¥98–199/月（ToDesk/向日葵） | 09 基准 |
| 云主机成本 | 2C2G 目录价 ¥45/月，活动低至 ¥38/年（≈¥3.2/月） | 09 基准 |
| 云电脑双轨 | 无影：包月 ¥9.9–149.9 + 灵豆按小时（4 核 ≈ ¥0.12–0.20/h） | 09 基准 |
| 模型 API 成本 | DeepSeek V4-Flash 空闲档：输出 ¥4.5/百万、缓存命中输入 ¥0.05/百万 | 10 基准 |

### 6.2 三线定价模型建议（待定稿，价格留待讨论）

- **08 托管 hub**：订阅制，锚 **$20/月个人档**（Free 档拉新）+ 团队按席位；价值在"免部署 + 免公网 + 账号"，可加"多机器数"分层（host 数配额）。
- **09 云端 DSH**：**双轨 = 包月套餐 + 按小时算力**（对标无影灵豆；成本锚 2C2G ¥45/月目录价，转售有 2–5 倍加价空间、按小时靠低利用率毛利更高）；个人锚 $20 档、重度 $100–200 档；免费档 = 每月少量小时数做漏斗。
- **10 Token 转售**：**成本 pass-through + 固定平台费/会员费**（OpenRouter 式 5.5% 量级），不做固定倍率（DeepSeek 价格波动剧烈：75% 降过、1100% 涨过、停过充值）；或"订阅含额度 + 超量按量"；用官方 `user_id` 做多租户隔离、错峰 + 缓存命中优化压成本。

### 6.3 差异化定价卖点

- **"额度可结转 / 账单可预期"**（vs 竞品"积分不结转、消耗不可预测"）——用明确单位价（每小时/每百万 token）而非积分黑盒。
- **"免 key + 免机器 + 免部署"三合一**的打包价值，支撑高于纯远控（¥10-25/月）的客单价。

## 7. 渠道与 GTM

1. **开源获客**（MIT + GitHub）：`npm i -g remote-dsh` 自托管用户 = 天然漏斗，向 SaaS 托管升级。
2. **DSH / DeepSeek 生态**：dsh 插件（`dsh-web-remote`）已入 DSH 生态；DeepSeek 开发者社区、Hugging Face 等。
3. **内容/博客**（zh/en）：发布向教程走 `doc/blog/`（未定内容不对外）；"浏览器免部署"对标"无影要装客户端"的话术。
4. **微信生态/社交媒体**：微信内浏览器已实测可用，分享链接即触达（先于小程序）。
5. **M8/M9（品牌渠道，后置）**：App/小程序作为应用商店曝光与微信生态入口，非功能必需（2026-08-26 定案）。

## 8. 风险与假设

| 风险 | 说明 | 应对 |
|---|---|---|
| **竞争** | 大厂免费/补贴（Coze 免费、元器平台免费模型按量、百炼送 7000 万 tokens） | 差异化在"远程访问 + 环境托管"，不正面拼模型/搭建平台 |
| **成本波动** | DeepSeek 官方价剧烈波动 + 曾停充 | 10 用 pass-through + 平台费，预留调价传导；向上游争取官方代理 |
| **合规** | 10 转售条款**待官方确认**；号池/反向代理是刑拘红线；09 云资源转售 B11；08 EDI 已确认不适用 | 只做正规额度转售/自持 key 代理；办资质+备案+AI 内容标识；逐条核红线 |
| **授权红线** | Dify 开源禁多租户 SaaS；DSH 生态授权待核 | 08 用户自带机器（轻资产）；09 前核查 DSH 授权 |
| **付费意愿未验证** | 技术已验证（浏览器实测可用），但"愿付费"尚未验证 | S1 免费试用 + 转化漏斗先测；08 先于 09/10 |

## 9. 战略判断（用户三问，2026-08-26）

> 背景：01-07 开源轨（远程访问层）已满足自身与同事日常使用、开源回馈社区；08-x 商业化轨面向更广人群（含无编程背景），处于 AI 风口，有机会也有风险与竞争压力。以下是对用户三问的诚实回答，作为战略决策的事实基础。

### Q1 能不能在 AI 时代给普通人创造价值？—— 能，但要诚实定义"普通人"

| 人群 | 01-07 覆盖 | 08-x 首版覆盖 | 完整覆盖 |
|---|---|---|---|
| 开发者/技术人群（DSH 用户） | ✅ 已满足（自托管） | ✅ 免部署/免公网 | — |
| **准技术人群**（分析师/运维/小团队：会用但不想折腾部署） | ❌ | ✅ **08-x 首版真实价值对象** | — |
| 完全不碰技术的白丁 | ❌ | ❌ | 需等 AaaS（任务驱动 UX，"一句话派活"） |

- 品类已被 $2B 级交易验证（Manus）；我们的价值 = 帮 DSH 生态与准技术人群省掉"部署、机器、公网"三件事；
- **别把"白丁"当首版 KPI**——首版吃准技术人群，白丁是 AaaS 愿景。

### Q2 要不要把技术优势转成商业机会、赚合理合法的钱？—— 意愿由公司拍板，事实与框架如下

- **合规路径清晰**：招行聚合支付 + 经营性 ICP 已有 + EDI 不适用（08 已核）；10 转售授权待 DeepSeek 官方确认；
- **窗口真实但红海**：AI 风口 + 品类验证 + 轻资产路径（用户自带机器 vs Manus 重算力）；但大厂免费补贴（Coze/元器/百炼）挤压独立玩家；
- **建议：小步验证替代拍板**——先做 08 S1（注册/试用/配额，零支付依赖、成本最低），用真实数据回答"有没有人注册、试用转化率多少"，这是付费意愿的第一个数据点。

### Q3 有没有真竞争力（技术 + 商业）？—— 技术强，商业未验证

- **技术竞争力（强）**：远程访问/隧道/多租户/安全整层连接骨架（Manus 估值的大头之一），DSH 开源底座 + DeepSeek 低价模型；竞品（重算力自营）需自造这层；
- **商业竞争力（未验证）**：无品牌/流量/渠道；对手有资金与分发。三个真实变量：
  1. **获客成本 vs 客户终身价值**——最大未知数，未跑过；
  2. **差异化空白真实但窗口有限**——"浏览器免部署"暂无人占位，大厂随时可补；
  3. **护城河候选**——机器已 join hub（迁移成本）、开源社区品牌、DSH 生态绑定。

### 战略结论（一句话）

**01-07 开源轨继续**（品牌资产 + 获客漏斗，零成本维护）；**08-x 用 S1 最小验证启动**（免费试用 → 付费漏斗），用真实转化数据证明商业模式；**不与巨头正面竞争，终点是"证明资产价值 → 以好价格出售/合作"**（见下）。

### 战略取向修正（2026-08-26 用户定案）：从"竞争"转向"证明 + 出售/合作"

- **不把大厂当对手**：无品牌/流量/渠道，正面竞争是死路；改为——**证明技术 + 商业模式跑通，然后以好价格卖给巨头 / 与巨头合作，换取顶级资源支持**（Manus 先例：$2B 被 Meta/腾讯收购）；
- **核心洞察**：rdsh 的真正资产是 **"agent 连接层"**——巨头不缺模型/云端，缺的是"让 agent 在用户自己的机器/任意环境上可用"的连接层（出站隧道 + 认证网关 + 多租户路由）；MIT 开源 + 层 1/层 2 契约冻结 + 插件化 = **可被白标/集成/收购的资产形态**（"gateway 永不需要改动"的承诺即为被集成设计）；
- **要证明的三件事**：① 技术被真实使用（host 数/隧道活跃/留存）；② 商业模式跑通（试用→付费转化、MRR、成本毛利）；③ **资产可嵌入**（契约稳定、插件化、文档齐，巨头买回/集成不费劲）；
- **潜在的出售/合作对象**（时机成熟后）：DeepSeek（DSH 生态 + 模型）、阿里云（无影/百炼/轻量转售）、腾讯（元器/Manus 生态）、云厂商（批量资源/转售通道）；
- **对产品的含义**：优先打磨"连接层资产"（08 + dsh 插件 + 协议契约）；09/10 在"出售/合作"叙事里非核心（巨头自有云与模型），作为商业模式证明的补充；KPI 从"获客规模"转向"**验证效率 + 资产稀缺性 + 合作伙伴意愿**"；
- **诚实提醒**：出售/合作是**结果**不是目标——先做出可验证价值；"好价格"取决于营收、资产稀缺性与谈判时机；合作可能带排他/股权条件，谈判前保持独立性。
