# 隐私政策

更新日期：2026-09-01

## 1. 我们收集的信息
- 账号信息（您主动提供）：邮箱 / 手机号（用于注册、验证、登录与找回）、密码（仅存不可逆哈希）。
- 微信登录信息（您使用「微信登录」时）：微信 `openid`、`unionid`、昵称与头像（仅用于识别账号身份、账号归并与界面展示）；**不存储微信 `access_token`**，仅在登录授权时临时使用。
- 设备信息（接入时自动记录）：您接入的 host 名称与连接元数据。
- 日志信息（自动记录）：访问与安全审计日志（IP、时间、事件），用于安全与风控。

## 2. 信息使用目的
为您提供账号体系（含微信登录）、远程访问、订阅计费与安全防护；向您发送验证码（邮箱/短信）与必要的服务通知。微信 `openid`/`unionid` 用于将同一微信用户跨应用（网页 / 小程序 / 移动端）归并到同一账号。

## 3. 信息存储与保护
数据存储于境内服务器，不向境外传输。密码仅存哈希，验证码仅存哈希且一次性有效；微信登录仅存 `openid`/`unionid`/昵称/头像，不持久化 `access_token`；日志脱敏并按期清理（默认保留 90 天）；账号信息保留至您注销账号。
您接入主机的 DSH 会话流量仅经本服务中转，我们不对其内容进行缓存、存储或审查；连接日志仅含元数据（IP、时间、事件），不含流量内容。

## 4. 第三方服务
为提供服务，我们可能将必要信息提供给以下第三方：邮件服务（阿里云 DirectMail）、短信服务（阿里云短信）、人机验证（阿里云验证码）、微信登录（腾讯微信开放平台）、支付通道（微信支付 / 招行聚合）。上述第三方仅按需获得最小必要信息。

## 5. 您的权利
您可随时查看、更正、撤回同意或注销：可在「设置」中绑定/解绑邮箱、手机号与微信；可自助删除账号（「设置」→「删除账号」），删除后个人数据将被清除，账务记录按法定要求保留必要字段。

## 6. 未成年人保护
本服务面向有完全民事行为能力的用户。若您为未成年人，请在监护人指导下使用。

## 7. 政策更新
本政策更新时，我们将在本页面公示。重大变更将另行通知。

## 8. 联系我们
如对本政策或个人信息处理有任何疑问，请通过官方渠道与我们联系。
