# 获取接入令牌（join token）：把电脑绑定到你的账号

> 2026-09-08 · rdsh.cn 云服务
> rdsh.cn 上手系列：① 注册账号 → **② 获取接入令牌（本文）** → ③ 三种接入方式 → ④ 账号安全

---

## 这一步是干什么的

账号建好之后，要让某台电脑能被远程访问，先要把这**台电脑绑定到你的账号**。绑定用的凭证叫**接入令牌（join token）**，整个流程是：

```
登录 rdsh.cn →「添加主机」→ 生成一张一次性令牌
  → 在电脑上用令牌完成接入 → 电脑绑定到你的账号 → 随时可进入
```

令牌是一张**一次性、用完即弃**的临时凭证，不是长期密码：生成后尽快在电脑上用掉；电脑完成接入后就**固定归你的账号管**，不再依赖这张令牌。

## 步骤

### ① 在网页上生成令牌

1. 登录 **[rdsh.cn](https://rdsh.cn)**；
2. 点「**添加主机**」→ 给电脑起个名字（比如 `我的开发机`，之后在列表里认它用）；
3. 选**有效期**（默认 30 天，可改）；
4. 点「生成」→ 页面会显示要复制的内容，**只显示这一次**，并按你打算怎么接入分成两种方式，各给对应的「复制」按钮：
   - **方式一：DSH 插件**——需要**服务地址**和**令牌**两样东西：页面上「Hub 地址」指的就是 rdsh.cn 这个网址，它和令牌各有一个「复制」按钮（「复制 Hub 地址」「复制令牌」）；
   - **方式二：命令行**——只需要**一条现成命令**，点「复制命令」即可，形如：

     ```bash
     rdsh host join https://rdsh.cn --token <t>
     ```

> 插件用户注意：把页面上的「**Hub 地址（服务网址）+ 令牌**」两样**分别复制**好，到 DSH 插件的「远程访问」面板里对应粘贴即可（主机名在面板里自己填一个）。命令行用户则只需执行复制到的那条命令。

### ② 把令牌交给电脑

拿到内容后，去那台电脑上按你选的接入方式操作（插件 / 命令行各有教程，会一步步带你）。执行成功后，这台电脑就**绑定到你的账号**、固定出现在你的主机列表里——以后重启、换网络都不用再弄一次。

### ③ 选一种接入方式

接入方式三选一（一台电脑同时只跑一种）：

- **DSH 插件**——电脑上已在跑 DSH 网页版，想少装东西：界面里点几下就接入；
- **命令行前台**——喜欢命令行、看得见日志：执行 `rdsh host join`（上面那条命令），再运行 `rdsh host serve`；
- **后台服务**——想一直在线、开机自启：用 `rdsh host service install`（同一条命令能变成服务）。

每种都有专门教程，按你选的那篇走即可。

## 电脑接进来之后，它安全吗？

- **它是"只认你"，不是"开了门"**——绑定后只有你的账号能进入它；别人看不到，也进不去（除非你主动分享）；
- **路上内容是加密的**——你远程查看、操作的对话与文件都是密文，中转服务读不到内容；
- **可以在电脑上再加一道锁**——设一个只属于你的主机访问密码（可选，随时可开可关）：任何其他人，包括服务方，都过不去；
- **随时可以停用**——不用时暂停接入；想彻底解除也能解绑，电脑立刻回到只属于你本机，接不接入始终由你决定。

## 关于令牌，几句话讲清楚

- **只显示一次**：明文只在生成那刻出现，服务方不保存副本——像对待一串临时密码：生成后立刻用，丢了就重新生成一张；
- **归你账号所有**：用它接入的电脑出现在你的列表，别人看不到；
- **有有效期**：默认 30 天，可以改；过期了就重新生成；
- **可随时作废**：在列表里删掉这张令牌，只影响**还没用它接入**的电脑，已经接入的不受影响；
- **一张令牌能接多台**：可以给家里的和办公室的电脑各用一次同一张令牌，各自独立管理。

## 常见小问题

- 页面上「方式一 / 方式二」是什么？分别对应插件和命令行两种接入——用插件就复制地址 + 令牌，用命令行就复制整条命令，选一种即可；
- 执行时提示令牌无效/已过期？重新生成一张再试；
- 想不起令牌是给哪台电脑的？在列表里看名字，名字随时可以改。
