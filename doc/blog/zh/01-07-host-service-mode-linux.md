# 后台服务 · Linux：开机自启常驻，在哪都能安全连回你的 DSH

> 2026-09-08 · rdsh.cn 云服务
> rdsh.cn 上手系列：③ 接入方式三：后台服务 —— **Linux（systemd）篇（本文，已实测）**（macOS / Windows 另有分篇）

## 适合谁 / 什么场景用得上

你的电脑要**长期在线**，不想有人守着终端——常开的台式机、放在机房或家里角落的 Ubuntu 机器。这样的电脑通常用来跑 DSH，常见用法：

- **云服务器管理**——在一台常开的 ECS / 云主机上跑 DSH：你在任何地方的浏览器里登录它，让智能体帮你做部署、查日志、跑脚本这类服务器上的事；
- **云开发环境**——把开发工作交给跑在云主机上的 DSH：出差在外，用手机、平板或任何一台电脑的浏览器都能接着干；
- **家里的"智能体工作站"**——常开机跑 DSH 处理长任务（分析、写代码、跑工作流、整理文件）：人在外面随时打开浏览器看进度、派新任务；
- **无人值守的构建 / 批处理机**——自动化任务常驻运行，到点或远程一触发就开始，不需要有人守着；
- **低功耗"家庭智能体小主机"（如树莓派）**——用一块 ARM 小板常开跑 DSH，安静省电、放在角落里当个人 AI 助手主机。

> 关于树莓派等 ARM 板：理论上可行——只要能装 Node.js ≥ 22 并正常安装 `dsh`，后续流程与本文完全一致。**我们尚未在树莓派上实测**：如果你按本文在树莓派上跑通，欢迎告诉我们结果，我们会把这里标记为实测过。

它们的共同点是：**电脑要一直在线，但没人守在它面前**——这正是后台服务要做的事。装成后台服务后，这台电脑会：

- 开机自动连上 rdsh.cn（无需人操作）；
- 连接进程意外退出会自动拉起；
- 不占终端窗口，日志进系统服务日志。

## 你需要先有

- 一台 Linux 电脑（Ubuntu 等主流发行版均可），装好了 `dsh`（服务会自动拉起 DSH 网页版）；
- 一个 rdsh.cn 账号（令牌用的时候现生成即可）。

## 开始：一条命令装好

先登录 rdsh.cn →「添加主机」→ 点生成，把显示一次的**令牌**复制下来（临时凭证，用完即弃，丢了再生成一张即可）。然后在这台电脑的终端里执行：

```bash
npm i -g remote-dsh        # 第一次才需要
rdsh host service install https://rdsh.cn --token <t> --name my-host
```

（把 `<t>` 换成刚才复制的令牌。）这一条命令完成全部：**用令牌绑定电脑 → 写好配置 → 安装并启动后台服务**。

> 已经用命令行方式接入过？直接运行 `rdsh host service install` 即可（配置和绑定都还在），不用再给令牌。

## 验证装好了

- **看状态**：`rdsh host service status` → 显示 `active (running)`；
- **看日志**：`journalctl --user -u rdsh-join -e`；
- **最直接的确认**：浏览器登录 **rdsh.cn** → 主机列表 → 这台电脑显示**在线**。

## 开机自启的细节（请读一下）

服务是**用户级**的：电脑开机、该用户登录后才会自启。对"无人值守的服务器"：

```bash
loginctl enable-linger $USER
```

执行一次后，**开机即启、无需任何人登录**。桌面电脑则照常（登录后自启），不用额外设置。

## 日常操作

- **手动重启**：`rdsh host service restart`（等价于 `systemctl --user restart rdsh-join`）；
- **彻底移除**：先 `rdsh host service uninstall` 停掉并删除服务，再 `rdsh host leave` 解绑——顺序别反；
- **改名**：登录 rdsh.cn → 主机列表 → 点这台电脑的「改名」，网页上直接改；
- **升级 Node / 重装 remote-dsh 后**：服务指向的路径可能变化——重新执行一次 `rdsh host service install` 即可。

## 电脑接进来之后，它安全吗？

- **它是"只认你"，不是"开了门"**——接入后只有你的账号能进入它；别人看不到，也进不去（除非你主动分享）；
- **路上内容是加密的**——你远程查看、操作的对话与文件都是密文，中转服务读不到内容；
- **可以在电脑上再加一道锁**——设一个只属于你的主机访问密码（可选，随时可开关）：任何其他人，包括服务方，都过不去。
