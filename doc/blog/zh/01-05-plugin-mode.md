# 装个插件，在哪都能安全连回你的 DSH

> 2026-09-08 · rdsh.cn 云服务
> rdsh.cn 上手系列：① 注册账号 → ② 获取接入令牌 → **③ 接入方式一：桌面版插件（本文）**（命令行版见本系列「CLI 模式」一篇）

---

## 为什么值得：远程、随时、安全

- **随时**：你的 DSH 智能体在电脑上干活，你在**任何地方**（手机、平板、任何一台电脑的浏览器）都能看到它干到哪一步、随时派新任务——长任务不用守在机器前，"人不在，活不停"；
- **安全**：这一切走的是加密连接：远程看到、操作的对话与文件都是密文，只有你的账号能进入你的电脑——在外面用，和坐在它面前一样安心。
- **选工作区不卡壳**：装好插件后，DSH 的目录选择器会固定为**浏览器内**的目录浏览器——远端也能浏览这台电脑的文件系统、直接新建目录（DSH 原生的系统选择框会弹在这台电脑自己的屏幕上，你在远端够不到）。

## 怎么做到：两条路，任选一条

- **DSH 桌面版**：装一个叫 `dsh-web-remote` 的插件，DSH 里就会出现「**远程访问**」面板——填服务地址 + 令牌，点「接入」；
- **命令行版（CLI）**：**不需要装插件**——`npm i -g remote-dsh`，然后 `rdsh join` 接入。

两条路能力一样，按你习惯选；本文先讲桌面版插件（CLI 见系列「CLI 模式」）。

## 你需要先有

- 这台电脑上的 DSH 能正常打开（桌面版，或 `dsh web`）；
- 一个 rdsh.cn 账号，和一张接入令牌（还没弄？按系列前面两篇走：先注册账号，再在 rdsh.cn 上「添加主机」生成令牌）；
- **仅桌面版插件**：装插件时会用到 `pnpm`（它不是 npm 的一部分——没有就先装一个：`npm i -g pnpm` 或 `corepack enable pnpm`）。

## 开始（桌面版）

### ① 安装插件

1. 打开 **DSH 桌面版** → 左上角「**插件**」→ **安装第三方插件**；
2. 填入插件名 `dsh-web-remote`，装好后打开插件面板——它在 DSH 里显示为「鲸语通语音助手」（英文 WhaleLink Voice）。

### ② 绑定本机

1. 先在 rdsh.cn「添加主机」生成的页面上，**分别复制「Hub 地址」和「令牌」**两样（页面只显示一次；丢了就重新生成一张）；
2. 在插件面板里填三样：**服务地址（Hub 地址）**、**令牌**、以及一个**主机名**（随意起，在列表里认它用），点「**接入**」→ 状态变成「已连接」；
3. 也可以直接**掏出鲸语通 App 扫码**（推荐，最快，不用来回复制）；
4. 以后在任何地方的浏览器登录 rdsh.cn → 主机列表 → 点这台电脑，就是完整的 DSH。

### ③ 日常用起来

- **暂时不用**：点「断开」暂停接入——令牌还在，想用时点「接入」就恢复，不用重新粘贴；
- **断线了**：它会自动重连，不用管；
- **彻底不要了**：点「注销」，回到未接入状态。

面板上的状态一眼能懂：

- **已连接**：现在可以从外面访问它；
- **连接中 / 重连中**：正在连接，或断线后自动恢复中；
- **未接入**：还没接入过，或已注销；
- **由命令行托管**：这台电脑正被命令行方式连着，面板此时只读（同一台电脑同一时刻只会由一种方式连接）。

## 或者：命令行版（不需要插件）

```bash
npm install -g remote-dsh
rdsh join                       # 省略 hub 地址会打印二维码，用鲸语通 App 扫码绑定本机
rdsh serve                      # 前台运行；常驻开机自启用 rdsh service install
```

## 电脑接进来之后，它安全吗？

- **它是"只认你"，不是"开了门"**——接入后只有你的账号能进入它；别人看不到，也进不去（除非你主动分享）；
- **路上内容是加密的**——你远程查看、操作的对话与文件都是密文，中转服务读不到内容；
- **可以在电脑上再加一道锁**——在面板里设一个只属于你的主机访问密码（可选，随时可开关）：任何其他人，包括服务方，都过不去；
- **不用时随时断开**——面板点「断开」即暂停接入，要用再连；想彻底不要了可「注销」，电脑立刻回到只属于你本机。
