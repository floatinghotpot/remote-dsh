# 装个插件，在哪都能安全连回你的 DSH

> 2026-09-08 · rdsh.cn 云服务
> rdsh.cn 上手系列：① 注册账号 → ② 获取接入令牌 → **③ 接入方式一：插件（本文）**（另两种接入方式见本系列第 ③ 步之后）

---

## 为什么值得：远程、随时、安全

- **随时**：你的 DSH 智能体在电脑上干活，你在**任何地方**（手机、平板、任何一台电脑的浏览器）都能看到它干到哪一步、随时派新任务——长任务不用守在机器前，"人不在，活不停"；
- **安全**：这一切走的是加密连接：远程看到、操作的对话与文件都是密文，只有你的账号能进入你的电脑——在外面用，和坐在它面前一样安心。

## 怎么做到：装一个插件

装一个叫 `dsh-web-remote` 的插件，DSH 的设置里就会出现一个「**远程访问**」面板：把服务地址和令牌填进去，点「接入」就完成了。它和命令行是同一套能力，只是**入口做进了界面**——不用为这件事装命令行工具，也不用折腾后台服务（前提：这台电脑上已经在跑 DSH 网页版 `dsh web`）。

## 你需要先有

- 这台电脑上的 DSH 网页版能正常打开（`dsh web`）；
- 一个 rdsh.cn 账号，和一张接入令牌（还没弄？按系列前面两篇走：先注册账号，再在 rdsh.cn 上「添加主机」生成令牌）；
- 电脑上能运行 `pnpm`（装插件会用到；它不是 npm 的一部分——没有就先装一个：`npm i -g pnpm` 或 `corepack enable pnpm`）。

## 开始

### ① 安装插件

在电脑的终端里执行：

```bash
dsh plugin --profile web add dsh-web-remote
```

这条命令就是把插件装进 DSH 网页版（装完可用 `dsh plugin --profile web ls dsh-web-remote` 看一眼，能列出就说明装好了）。

### ② 重启 DSH 网页版

```bash
# 先 Ctrl+C 停掉正在跑的 dsh web，再重新启动（插件在启动时加载，不是即插即用）
dsh web
```

启动后会打印一个网址并（通常）自动打开浏览器——用这个网址进 DSH 网页版。

### ③ 打开「远程访问」面板，点接入

1. 先在 rdsh.cn「添加主机」生成的页面上，**分别复制「Hub 地址」和「令牌」**两样（页面只显示一次；丢了就重新生成一张）；
2. 在 DSH 设置里找到「**远程访问**」面板，填三样：**服务地址（Hub 地址）**、**令牌**、以及一个**主机名**（在列表里认它用的名字，随意起）；
3. 点「**接入**」→ 状态变成「已连接」；
4. 以后在任何地方的浏览器登录 rdsh.cn → 主机列表 → 点这台电脑，就是完整的 DSH。

> 小贴士：如果这台电脑之前已经用命令行接入过，重启后它会**自动接上**，这一步可以跳过。

### ④ 日常用起来

- **暂时不用**：点「断开」暂停接入——令牌还在，想用时点「接入」就恢复，不用重新粘贴；
- **断线了**：它会自动重连，不用管；
- **彻底不要了**：点「注销」，回到未接入状态。

面板上的状态一眼能懂：

- **已连接**：现在可以从外面访问它；
- **连接中 / 重连中**：正在连接，或断线后自动恢复中；
- **未接入**：还没接入过，或已注销；
- **由命令行托管**：这台电脑正被命令行方式连着，面板此时只读（同一台电脑同一时刻只会由一种方式连接，不会重复）。

## 电脑接进来之后，它安全吗？

- **它是"只认你"，不是"开了门"**——接入后只有你的账号能进入它；别人看不到，也进不去（除非你主动分享）；
- **路上内容是加密的**——你远程查看、操作的对话与文件都是密文，中转服务读不到内容；
- **可以在电脑上再加一道锁**——在面板里设一个只属于你的主机访问密码（可选，随时可开关）：任何其他人，包括服务方，都过不去；
- **不用时随时断开**——面板点「断开」即暂停接入，要用再连；想彻底不要了可「注销」，电脑立刻回到只属于你本机。
