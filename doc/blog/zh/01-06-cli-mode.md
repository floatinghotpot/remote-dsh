# 一条命令，在哪都能安全连回你的 DSH

> 2026-09-08 · rdsh.cn 云服务
> rdsh.cn 上手系列：① 注册账号 → ② 获取接入令牌 → **③ 接入方式二：命令行（本文）**（另两种接入方式见本系列）

---

## 适合谁

你习惯用命令行：在电脑的终端里操作、想看得见连接日志、随时按一下就能停。也适合你在机器上只有 SSH、没有图形界面的情况。

命令行接入是这样两条命令：

```
rdsh host join https://rdsh.cn    # 首次绑定：按提示粘贴接入令牌（会自动记住）
rdsh host serve                   # 之后每次：前台运行建立连接，不再需要令牌
```

> 注意：`serve` 是**前台**程序——终端别关（关了连接就断）。想要"开机自启、不用人守着"的是另一种接入方式（后台服务），见本系列。

## 你需要先有

- Node.js ≥ 22；
- 电脑上装有 `dsh`（`serve` 会替你拉起 DSH 网页版；若 dsh 不在默认位置，可用 `--dsh <路径>` 指定）；
- 一个 rdsh.cn 账号，和一张接入令牌（还没弄？按系列前两篇走）。

## 开始

### ① 安装

```bash
npm install -g remote-dsh
```

### ② 绑定这台电脑

去 rdsh.cn「添加主机」页面点「**复制命令**」，回到终端**直接粘贴执行**——复制到的命令已经带好令牌：

```bash
# 复制到的命令形如：
rdsh host join https://rdsh.cn --token <t>
```

完成后会看到"已接入 https://rdsh.cn"，接着运行下一步的 `rdsh host serve` 即可。

> 小知识：`join` 只负责"绑定并记住"（一次性的，之后不用再输令牌）；真正建立连接的是下一步的 `serve`。

### ③ 前台运行

```bash
rdsh host serve
```

它会自动拉起 DSH 网页版（如果没在跑）并建立到 rdsh.cn 的连接，日志里能看到连接状态。

### ④ 验证

浏览器登录 **rdsh.cn** → 主机列表 → 这台电脑显示**在线** → 点击即可进入完整的 DSH。

## 日常用起来

- **停一下**：`Ctrl+C`（连接随之断开，干净退出）；
- **再开**：`rdsh host serve` —— 不用重新输令牌，直接连上；
- **彻底解绑**：`rdsh host leave` —— 电脑立刻回到只属于你本机。
- **改名**：登录 rdsh.cn → 主机列表 → 点这台电脑的「改名」，在网页上直接改。

## 电脑接进来之后，它安全吗？

- **它是"只认你"，不是"开了门"**——接入后只有你的账号能进入它；别人看不到，也进不去（除非你主动分享）；
- **路上内容是加密的**——你远程查看、操作的对话与文件都是密文，中转服务读不到内容；
- **可以在电脑上再加一道锁**——设一个只属于你的主机访问密码（可选，随时可开关）：任何其他人，包括服务方，都过不去；
- **不用时随时停**——`Ctrl+C` 停下就暂停接入，要用再 `rdsh host serve`；想彻底不要了执行 `rdsh host leave` 解绑，电脑立刻回到只属于你本机。

## 三种不同的使用方式

本系列覆盖三种接入方式，任选其一即可：

- **插件方式**——想在 DSH 界面里点点、少装东西：设置里填服务地址与令牌就接入（见本系列插件篇）；
- **命令行方式（本文）**——习惯终端、想看日志、随时 Ctrl+C 停；
- **后台服务方式**——想开机自启、不用人守着（见本系列后台服务篇）。

同一台电脑**同一时刻只由一种方式连着**：命令行占着时，插件面板会显示只读提示，避免重复连接。
