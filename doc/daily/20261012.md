## 跨域 cookie 根域 + 默认 relay 增强

- `rootDomain()`：从请求 Host 自动算根域（`rdsh.cn`→`.rdsh.cn`、`cn-relay-01.rdsh.cn`→`.rdsh.cn`）
- 会话/续期/主机 cookie 都带 `Domain`；`hostCookieDomain` 配置优先，没配才 auto-calc（`5dff434`）
- `defaultRelayUrl` 配置：hub 内置 relay（node=null）的 host，在 host 列表 `nodeUrl` 与进入 302 都返回该 URL，强制走 relay 避免与站点根路径混用
- 两个 bugfix（`553c5fd`）：`runtime.config` 构造漏传 `defaultRelayUrl`；logout 清 cookie 域名与 SET 不匹配（清不掉）
