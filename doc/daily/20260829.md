### 动机

- 主机名是「每次 join 的参数」而非「令牌属性」——令牌可复用于多台主机，创建时钉死名字语义错位
- gateway 统一 hostname 默认后，hub 端主机显示名与本地 host.json 一致（此前 CLI 本地默认 hostname 但 hub 端是 `host-xxxx`，两头对不上）
- 插件路径此前连 host.json name 都没写，一并修复
